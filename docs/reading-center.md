# 统一阅读中心

阅读中心将最近阅读、稍后阅读和继续阅读放在一个入口。首版随 Oxygen 2.0.40 提供，模块版本 1.0.0；LTS 不包含此新模块。

## 打开与使用

- legacy 宽屏：左侧工具 → 阅读中心。
- ios27：工具 → 插件功能 → 阅读中心。
- 无皮肤或 legacy 窄屏：右下角 H → 阅读中心。

「最近阅读」按最后访问时间排序，点击标题或「继续阅读」回到保存的页码和楼层。回访主楼会刷新访问时间，并保留之前的后页断点；读到更后的楼层时更新断点。标题或主题 ID 搜索只检索本地记录。

列表标题旁、正文标题下和历史条目内都有「稍后阅读」按钮。加入后可以在「稍后阅读」中找到；再次点击标题旁按钮或「移出稍后阅读」即可移除。移出队列不会清除阅读断点。稍后阅读按加入时间排序，继续阅读时使用最新的断点；缺少断点则打开帖子主楼。

队列最多 500 帖，按主题 ID 去重，不自动过期。达到上限时提示先移除条目，不会覆盖旧条目。列表每次显示 50 条，可以加载更多；搜索范围包含所有记录。

## 数据来源与边界

最近阅读直接复用断点续读的 `positions`，旧格式 `{ f, p, title, ts }` 无需迁移或重新抓取。默认保留 120 天、最多 500 帖，由「断点续读」设置控制；过期和损坏记录不会进入新阅读列表，已有的阅读历史清空入口继续保留。

稍后阅读存入 `lsb_base:reading-center:later`，结构为主题 ID 到 `{ title, addedAt }` 的映射。本地队列与站点收藏各自独立；它不表示已经读完，不会发送收藏请求。迁移插件的全库备份包含这些记录。

断点续读未安装、版本不支持查询接口或被停用时，阅读中心显示来源不可用说明，稍后阅读仍可打开主楼。重新启用断点续读后恢复按位置继续阅读。停用阅读中心只移除其 UI、监听和 RPC，不删除已保存数据。

打开、切换列表、搜索、加入和移除均不额外抓取站内页面；只有用户打开帖子时才发生正常导航。面板重开、手动刷新、窗口恢复焦点时重新读取本地值。同一浏览器内可从其他标签的已保存数据刷新，但不提供多个标签同时修改队列的事务合并；没有云端同步。

## 开发接口与验收

断点续读 1.0.6 提供所有页面可用的只读 RPC：

```js
await api.request('resume-reading:list')
await api.request('resume-reading:get', { topicId: 12 })
// { topicId: 12, title: '主题', floor: 82, page: 3,
//   updatedAt: 1793361600000, source: 'resume-reading',
//   href: '/topic/12?p=3&floor=82' }
// 未找到时 get 返回 null；list 返回按时间倒序的数组。
await api.request('reading-center:open')
```

返回值为独立记录，查询不改写存储。阅读中心不读取其他模块的私有存储，也不依赖 `:debug`。软导航时，追踪会话捕获主题 ID、页码和标题，离开时清理延迟保存、监听和提示 UI。

专项测试：`node --test --test-force-exit test/reading-center.test.js`。浏览器复验：`npm run smoke:reading`，包括 legacy / ios27 的桌面与 390px 触屏。具体范围和环境限制见 [双界面阅读验收](reading-acceptance.md)。
