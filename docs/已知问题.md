# 当前行为、限制与反馈

本页于 2026-10-31 按本地实现核对。当前源码版本与分发范围见 [开发规范](CONVENTIONS.md)，安装和完整功能清单见 [项目 README](../README.md)。

## 安装与功能范围

- 正式氢与氧配套使用；也可以只装精简合并版 LTS。LTS 与氢、氧不要同时启用。
- 正式 Hydrogen、Oxygen 和 LTS 均不包含 AI 专用 API、AI 模块或 skin AI 入口。完整 AI 功能仅在 `dist-dev/` 的开发氢与氧中提供，不能与正式版混装。
- LTS 冻结新功能，只处理安装、站点兼容、请求异常和数据丢失等维护问题；称号行情、UR 合成规划、积分-称号工作台不进入 LTS。完整成员范围由 [suite/order.js](../suite/order.js) 定义。
- `local-bridge` 是独立的本机联动插件，不进入氧或 LTS。

## 当前界面行为

- **界面模式**：氢壳默认使用旧三段式，可在「界面模式」切换为 iOS 27 单画布；关闭氢壳则恢复站点原生页面。反馈布局问题时请注明所选模式。
- **帖子软跳**：氢壳的帖子页软跳默认开启，可在设置中关闭。单画布软跳等待响应时保留旧正文并显示顶部进度线；通过响应验证后更新正文，后退和前进恢复滚动位置。不支持的路由、事务页面和写操作仍使用整页生命周期。
- **窄屏历史回位**：skin 2.0.41 修复了已复现的原生工具栏重排导致回位后偏移问题。390px固定页面搭配原生脚本的对照中，旧版保存280px后漂到292px，新版在恢复瞬间和500ms后均保持280px。该修复覆盖恢复初期的重排，不承诺抑制任意晚到的图片、字体或其它插件引发的布局变化。
- **外观**：保留 D 原生站点、A 平衡玻璃、B 沉浸视频、C 静态可读预设，以及透明度、模糊、字号、字体和视频设置。旧公告中的“墙纸 / 液态玻璃已撤”不适用于当前版本；动效和透明度可按偏好降级。
- **积分与称号**：统一入口为「积分-称号」，交易页仍有内嵌行情。旧全站行情浮层和独立合成规划页签已退出当前入口；工作台只读取与计算，不发送购买、抽取或合成请求。
- **熔炼页增强**：可全选材料、排除 SSR，默认排除 R 级“反贼”，并恢复本地选择。增强控件不会替用户提交熔炼。
- **通知**：通知红点读取站点原生状态，后台不通过打开通知页探测未读，以免改变已读状态。标题中的消息计数与站点个人通知不是同一来源。

## 已知限制

- **站点兼容依赖页面结构**：仓库中的 HTML 快照和解析测试只覆盖已有样本。站点更新后仍可能失配，定位时需核对出问题页面的当前 DOM。
- **权限不是浏览器沙箱**：插件与页面共享 JavaScript 环境，`permissions` 约束基座 API 调用，不隔离恶意插件；安装的模块应来自可信来源。
- **请求与选主有边界**：限速队列按页面基座实例工作，跨标签巡检通过心跳选主减少重复请求；启动、掉线检测和冲突收敛不是瞬时完成，不能保证从不收到站点限流响应。
- **写入结果可能未知**：网络中断或异常响应不代表服务器一定未处理。未知结果不自动重发；有结果检查器时仅做只读核对。
- **数据与开发版 AI**：配置主要保存在本地脚本存储；开发版 AI 会按用户操作把材料发送到配置的外部服务，API Key 明文保存在本地。导出配置、日志或截图前应移除 Key、Cookie 和私人内容。
- **验收范围有边界**：旧 skin 跳过项已逐项恢复或归并，跳过预算为 0。双界面阅读使用离线快照、Chromium 触屏模拟和真实同上下文多标签验证；这不等于线上站点、真实手机输入法或 Tampermonkey 安装验收。覆盖与命令见 [双界面阅读验收](reading-acceptance.md)。

## 反馈需要的信息

请附上以下内容，方便复现和区分版本问题：

1. 使用正式氢 + 氧、开发氢 + 氧还是 LTS，以及脚本面板中的版本号。
2. 浏览器、Tampermonkey 版本，以及相关模块和界面模式的设置。
3. 出问题的页面类型或去除敏感参数后的路径、操作步骤、预期与实际结果。
4. 是否涉及多标签、软跳、首次安装或旧配置升级，以及能否稳定复现。
5. 必要的脱敏运行日志；涉及写入时说明站点是否已经出现相应内容，不要为取日志重复提交。

新功能建议按当前氢、氧能力讨论；LTS 继续维持精简维护范围。归档公告中的旧版本上限和“本轮不修”不再作为当前限制。
