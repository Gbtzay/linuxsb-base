# 双界面阅读验收

本页记录 2026-10-30 对当前工作区的验收范围和旧测试迁移。开发与复验入口以 [开发规范](CONVENTIONS.md) 为准。

## 自动验收范围

- `test/reading-center.test.js`：首页复用旧断点、只读查询、回访保留位置、软跳会话隔离、搜索、队列持久化与容量、停用降级、跨标签数据刷新以及双界面入口与楼层目标。
- `scripts/reading-browser-smoke.mjs` 的 4 个阅读中心场景：两种界面分别在桌面/触屏从真实入口打开、加入队列、搜索、按页码和楼层续读、后退移除与停用；断言面板操作不抓取页面、正文目标可见、手机内容宽度及无横向溢出。
- `test/reading-acceptance.test.js`：两种模式各验证新回复等待草稿清空、编辑器与选区保留、模式切换保留原生节点、重复轮询不重复插入，以及停用后迟到响应和旧按钮失效、重新启用可用。
- `test/skin.test.js`：六类阅读路由情形分别运行 legacy 与 ios27，包括旧分页计时器、迟到分页响应、首页实时流与帖子实时流交叉返回、停用挂起导航、连续导航只提交最后一次请求。
- `scripts/reading-browser-smoke.mjs`：1440×1000 下两种界面的首次首页滚轮翻页、帖子往返与滚动恢复、草稿/选区保护、连续导航和停用归还原生节点；390×844 下启用 hasTouch/isMobile，通过触摸事件滑动、点击进入帖子和返回；同一 Chromium 上下文同时打开 legacy 与 ios27 标签，验证稳定单主轮询、关闭主标签后的接管和新回复插入。
- 原有 `smoke:legacy` 与 `smoke:ios27` 保留，继续覆盖布局、广告节点、更多历史导航、错误回退与媒体等场景。

`smoke:ios27` 对固定 HTML 样本屏蔽远程 JavaScript，只显式注入待测基座与 skin，避免线上脚本变化改写样本。原生 CSS 和图片仍从网络加载，因此该套件并非完全离线。窄屏历史用例在首页恢复后的下一帧重建原生标签换行类，确认工具栏重排后500ms仍回到保存的坐标，并检查临时样式已清理。阅读专项 `smoke:reading` 则保持下述离线响应策略。保留原生脚本的补充对照及修复范围见 [当前行为与限制](已知问题.md) 和 [第六步记录](superpowers/plans/2026-10-31-skin-lifecycle-split.md)。

## 本轮发现与修复

iOS 27 首次挂载画布时漏掉首页无限滚动绑定，只有后续路由刷新才进入公共绑定流程。新增双模式分页回归和 Chromium 首次滚轮翻页均在修复前失败；现在在界面挂载成功后统一同步无限滚动。皮肤升至 2.0.34，Oxygen/LTS 升至 2.0.39，氢版本保持 2.4.2。

基线完整 Node 回归为 1021 项：968 通过、1 失败、52 跳过。原有失败来自套件测试硬编码合成规划 0.1.2，而工作区源码已为 0.1.3；现改验 userscript 与 manifest 版本一致，产物成员和顺序检查保留。jsdom 不实现布局，阅读夹具将未滚动首页建模为长列表，只有模拟滚到底部的用例主动改变边界，避免零高度制造自动翻页。

相关回归：`npm run test:skin`。浏览器阅读专项：`npm run smoke:reading`。发布前执行 `npm run build:dev` → `npm run build` → `npm run verify:profiles` → `npm run verify:test-skips` → `npm run test:all` → `npm run smoke:browser`。

浏览器结果和触屏截图位于 `artifacts/reading-acceptance/`；失败场景额外保存截图与 Playwright trace。目录已由仓库忽略，不进入分发。所有网络响应来自离线快照，脚本会拒绝并报告非 GET 请求。

浏览器夹具提供最小原生布局 CSS，截图用于定位交互和布局问题，不作为线上主题的像素还原。触屏模拟不包含真实手机键盘、系统输入法候选窗、油猴沙箱、线上认证或真实广告脚本。页面事件和网络轮询是真实浏览器行为，站点响应与外部脚本被隔离；测试通过不代表覆盖这些边界。
