# Platform v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to execute this plan task-by-task. The user prohibits subagents; execute inline. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the local plugin/network/action security path with capability-scoped Platform v2 brokers while preserving the linux.sb server protocol and a working legacy facade.

**Architecture:** `PluginContext` owns capabilities and lifecycle disposers. `RequestBroker` validates every network intent before delegating transport to the existing GM/fetch implementation. `ActionBroker` validates confirmation, target scope, idempotency and result checks before delegating a single write. Existing `api.net`, `api.actions`, storage and UI methods become compatibility adapters over these brokers.

**Tech Stack:** JavaScript ES modules, node:test, JSDOM for DOM-backed CSRF fixtures, existing `src/net.js` transport and `src/core.js` registry.

**Spec:** `docs/superpowers/specs/2026-10-05-full-runtime-ui-rebuild-design.md`

## Global Constraints

- No server endpoint or CSRF field changes.
- No subagents; all steps run inline.
- Same-origin non-idempotent requests require `write`; external requests require `net`; missing capabilities fail closed.
- Non-idempotent requests never auto-retry; unknown write results only trigger a read-only check.
- No secrets in models, trace, plugin errors or persistent history.
- Base release floor is `0.2.0`; skin and suite compatibility are updated only when their source changes.

- [ ] **Step 1: Implement manifest capability normalization.** Accept only the existing capability names, deduplicate them, and freeze the result.

### Task 3: Implement RequestBroker over existing transport

**Files:**
- Create: `src/runtime/request-broker.js`
- Modify: `src/net.js` to expose a transport-only delegate without changing endpoint behavior
- Test: `test/runtime-request-broker.test.js`

**Interfaces:**
```js
new RequestBroker({ transport, snapshot, rate, trace }).request({
  owner, purpose, path, method = 'GET', external = false,
  routeScope, csrfMode = 'auto', signal, timeout, retryPolicy,
})
```

- [ ] **Step 1: Add URL and method validation.** Resolve relative paths against the current origin, reject cross-origin URLs unless `external:true`, and reject unsupported methods.
- [ ] **Step 2: Add capability and route-scope checks.** Use the caller context, require `read` for same-origin idempotent calls, `write` for same-origin mutations and `net` for external calls.
- [ ] **Step 3: Add CSRF injection.** For same-origin mutations read the current snapshot token or supplied form token; never include it in the returned envelope or trace.
- [ ] **Step 4: Add cancellation/timeout/rate/retry policy.** Abort before transport, default non-idempotent retry to zero, and normalize timeout/abort errors.
- [ ] **Step 5: Add response envelope and safe trace.** Return `{ ok, status, headers, text, json, document }` only for requested representations; redact diagnostics.
- [ ] **Step 6: Run focused tests.** Run `node --test test/runtime-request-broker.test.js`; verify no transport call occurs for every denied intent.

### Task 4: Implement ActionBroker

**Files:**
- Create: `src/runtime/action-broker.js`
- Modify: `src/ai-actions.js` to consume the broker for existing action providers
- Test: `test/runtime-action-broker.test.js`, `test/ai-actions.test.js`

**Interfaces:**
```js
prepare({ owner, actionId, summary, targetScope, routeFingerprint, args, schema })
confirm(pending, { nonce, userConfirmed })
execute(confirmed) -> { kind: 'success'|'unknown'|'failure', receipt }
check(receipt) -> { kind: 'confirmed'|'not-confirmed'|'unknown' }
```

- [ ] **Step 1: Implement schema and target validation.** Reject unknown action IDs, non-serializable args, stale route fingerprints, expired scope nonces and targets outside the local allowlist.
- [ ] **Step 2: Implement confirmation and idempotency.** Generate a single-use nonce and idempotency key; reject a second execute for the same key.
- [ ] **Step 3: Implement execute delegation.** Call the registered provider exactly once through RequestBroker and classify network/HTTP/business responses without storing raw bodies.
- [ ] **Step 4: Implement read-only checks.** Require a provider check function for unknown receipts and never call the write endpoint again.
- [ ] **Step 5: Run action regressions.** Run `node --test test/runtime-action-broker.test.js test/ai-actions.test.js`; existing safe-write tests must remain green.
