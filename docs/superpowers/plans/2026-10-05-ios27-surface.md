# iOS 27 Card Surface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to execute this plan task-by-task. The user prohibits subagents; execute inline. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the remaining shell geometry with a card-based iOS 27 reading canvas, shared SurfaceHost/SheetHost, semantic appearance controls and safe background media.

**Architecture:** The Reader Runtime owns one scroll root and one outlet. SurfaceHost owns only navigation/control/card surfaces. Card renderers consume PageDocument models and use semantic tokens. Background media remains below the reading surface; glass and card materials are optional and degrade to opaque panels.

**Tech Stack:** JavaScript ES modules, CSS custom properties, JSDOM, Playwright, IndexedDB through existing `src/shell-media.js`.

**Spec:** `docs/superpowers/specs/2026-10-05-full-runtime-ui-rebuild-design.md`

## Global Constraints

-正文采用卡片化玻璃布局；正文文字保持高不透明度和稳定行宽。
- Glass is limited to card/surface layers; no untrusted CSS text or arbitrary styles.
- Background image/video uses `z-index:0` and `pointer-events:none`; failures fall back to static/opaque surfaces.
- Respect reduced motion/transparency and keyboard/touch focus requirements.
- Skin phase floor is `2.2.0`; update the generated plugin and suite artifact versions together.
