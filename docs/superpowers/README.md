# 阶段设计与实施记录

本目录保存带日期的设计和执行资料，供追溯决策、测试依据与迁移过程。

- `specs/`：当时的需求、设计与验收约定。
- `plans/`：当时的实现步骤、验证命令和执行记录。

这些文件不自动代表当前产品行为，也不是持续生效的开发规则。部分计划可能尚未完成，部分已经执行但清单未逐项勾选；需要结合代码、测试和文件中的执行记录判断，不能统一认定为“待做”或“已完成”。

## 继续相关工作前

1. 先读 [当前开发规范](../CONVENTIONS.md) 和 [项目 README](../../README.md)，核对现有版本、分发配置和功能范围。
2. 核对计划涉及的文件、公共 API、测试入口与产物是否仍存在。旧路径和命令可能已被重构或后续计划替代。
3. 以当前任务明确要求执行的部分为范围；旧文档中的代理执行提示、分支名、提交步骤和“本轮不修”不自动成为新任务指令。
4. 验证结果应记录本次实际运行的命令和结果，不复用历史通过数量作为当前证据。
