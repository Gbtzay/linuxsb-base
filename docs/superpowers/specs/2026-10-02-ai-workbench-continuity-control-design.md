# M12：AI 工作台对话连续性与生成控制

用户于 2026-10-02 确认本规格方向，要求在当前会话执行且禁止子代理。实施目录为最新工作副本 `D:/test/linuxsb-base`，保留现有未提交功能。

## 对话连续性

工作台显式传入当前对话此前已完成的只读问答；新对话传入空数组，覆盖副驾原有按主题共享的会话。仅使用相同上下文范围的轮次，最多最近三组问答，历史正文不超过 4,000 字符且不超过当前正文预算的四分之一。预算保留当前材料优先级。历史作为不可信的对话背景，用于解析追问；不作为事实证据或站内动作授权。过滤写操作、未完成和失败轮次，沿用本地历史脱敏。

模型请求与计划、回答缓存键均包含实际采用的历史。引用仍只映射到本次本地材料。独立副驾入口在未提供 history 时保留既有行为。

## 停止与重试

生成和只读采集期间显示“停止生成”。通过 AbortSignal 贯通工作台、副驾、模型提供方和网络层，包括站内分页、退避等待及 GM 请求。停止立即释放输入，取消后不继续读取、缓存或更新会话；迟到回调和旧请求的 finally 不影响新的请求。新建/切换对话、路由切换和卸载取消正在进行的只读请求。

停止/失败轮次保留原问题，可手动重试同一轮。重试强制重新生成，不自动重发。实际站内写入期间不提供取消或重试入口，继续沿用已发送请求的 unknown 与结果检查机制；历史不进入写操作规划。

## 流式回答

回答支持 OpenAI Chat Completions 与 Anthropic Messages 的 SSE 文本增量。只显示回答文本，不显示推理字段。解析支持分片、CRLF、多行事件、UTF-8；在完整终止标记到达后才做引用校验并保存最终回答。流中断、协议错误和取消的部分文本不进入成功缓存或后续对话历史。

规划阶段继续使用完整 JSON。回答渲染期间使用纯文本，完成后使用现有安全 Markdown 和引用组件。兼容返回 JSON 的端点；明确拒绝 stream 参数的端点在尚未收到回答时最多降级一次，可通过设置关闭流式。已收到部分回答或取消后不降级重发。

## 验收

覆盖追问历史、空对话隔离、历史预算/脱敏、缓存命中差异、写授权隔离、停止网络和分页、迟到结果、立即重试、碎片化 SSE、双协议、异常流、JSON/不支持 stream 降级与最终引用校验。各阶段运行针对性回归，最终运行完整测试、三份构建、产物校验及本地浏览器交互验证。浏览器验证使用模拟端点，不发生真实站内写入或付费模型调用。
