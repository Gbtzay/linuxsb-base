# 新大陆式软跳迁移设计

## 目标

让氢壳软跳采用参考脚本“新大陆”的加载反馈和路由事务行为：保留同一颗氢壳与旧正文直到目标页面可提交；用顶部细进度条和新正文轻量进入动效代替正文区过渡胶囊；取消过期请求；正确恢复后退/前进的滚动位置、焦点与页面播报；将帖子页软跳设为默认开启。

## 依据与当前差异

参考脚本在导航请求期间显示顶部 3px 进度线，不用覆盖正文的加载层。响应通过路由验证后，脚本一次性替换正文出口，为新内容应用约 180ms 的淡入和轻微上移，并更新历史状态、滚动位置、页面标题和无障碍播报。它还通过 `AbortController` 中止旧请求，并在未保存编辑被浏览器后退时回滚历史指针。

当前 `plugins/skin.user.js` 已保留单一氢壳、旧正文到响应就绪前不移除、事务序号、页面级原生 UI 隐藏状态和页面缓存；它已有顶部进度条，但仍显示正文区过渡层，缺少请求中止、每个历史项的双轴滚动恢复、后退时未保存内容回滚、正文进入动效以及路由播报。帖子页软跳当前默认关闭，并会把既有开启配置迁回关闭。

## 设计

### 1. 迁移边界

`plugins/skin.user.js` 继续作为软跳的集成边界，不复制整份独立脚本。保留单一 `#lsb-shell`、当前页面缓存、正文出口提交、`fillShell()`、基座路由通知、帖子增强及站点侧栏恢复等集成路径。

路由判定继续使用当前已验证的站点白名单，并在默认启用的前提下纳入正整数帖子路由 `/topic/<id>`。保留 `/topic_collection/<id>` 和写操作为整页生命周期；不因参考脚本而开放当前未支持的 `/latest`。

帖子页设置项保留为用户退出开关，默认值改为开启。新增一次性存储标记 `topicSpaNewWorldDefaultMigrationV1`：第一次运行时把旧配置提升为开启并保存标记；之后用户手动关闭时不再被迁移逻辑覆盖。替换原有把帖子软跳强制关闭的启动迁移逻辑。

### 2. 导航事务与视觉反馈

事务继续由递增序号控制，并增加当前请求的 `AbortController`。开始新导航时中止上一个请求；只有当前序号仍拥有事务时，旧事务才可更新进度、DOM、URL、滚动或清理状态。通过现有 `api.net.raw()` 发送同源 GET，传入 `signal`、`queue: false`、15 秒超时和零重试；不直接绕过基座网络 API。

请求期间：
- 保留旧正文和现有氢壳，不提前改地址或销毁旧页面节点。
- 设置正文 `aria-busy`，持有 `lsb-canvas-route-pending`，使动态插入的原生顶栏、侧栏和浮动 UI 仍不可见。
- 在氢壳顶部显示一条 3px 进度线。请求不足 90ms 时不闪现；较慢请求显示加载阶段；提交后短暂走满并在约 220ms 后收起。
- 移除正文区居中的路由过渡胶囊，不再用它覆盖或截获正文交互。

完成响应检查后，先准备远端正文并应用原生 UI 隐藏标记，再同步历史地址、页面标题及现存 canonical/description/Open Graph 元信息，最后在同一提交阶段替换正文出口。新内容以约 180ms 的淡入和 5px 上移进入；`prefers-reduced-motion` 下取消位移和可见动画。页面级原生 UI 隐藏状态在新正文完成提交、壳已同步后释放。

响应只在最终地址仍属于允许的同源路由、正文出口存在且帖子 canonical 与目标帖子一致时提交。失败响应、登录跳转、人机验证页、错误帖子、无正文出口或解析失败均不得替换旧正文。

### 3. 历史、滚动、焦点和可访问性

每个软跳历史项保存命名空间化的软跳标记、历史索引、目标 URL 以及 `scrollX`/`scrollY`。离开当前页面前先写回当前项滚动位置；新路由成功验证后才 `pushState` 或 `replaceState`。后退/前进读取对应历史项位置，并在 DOM 提交后恢复；显式 `replyid`、`floor` 和 hash 定位优先于默认回顶。

带有未保存编辑内容时，点击导航先询问确认。浏览器后退触发确认且用户取消时，用历史索引差调用 `history.go()` 回到原项；回滚事件本身不得再发起请求。

由用户点击发起的成功导航在正文提交后将焦点移到正文出口，并通过氢壳内的 `role="status"`、`aria-live="polite"` 区域播报新标题。浏览器后退/前进不强制抢焦点。为每个正文出口设置可编程焦点所需的 `tabindex`，并使用手动滚动恢复避免浏览器和脚本重复滚动。

### 4. 失败、过期请求与停用

当前事务失败时先清除进度、`aria-busy`、页面级隐藏类和路由阶段，再按导航类型回退整页 `assign`、`replace` 或 `reload`。被新导航取代或被 `AbortController` 中止的旧请求不触发整页回退，也不得清理新事务的状态。皮肤停用、壳卸载和 `pageshow` 从缓存恢复时中止请求并清除定时器、进度状态和事务标记。

缓存命中仍使用相同的提交、滚动和页面通知规则；快速缓存提交不闪烁加载指示。保留当前缓存容量与淘汰策略，不为此改写缓存架构。

## 文件范围

- 修改 `plugins/skin.user.js`：路由事务、默认帖子软跳迁移、进度与正文动效、历史状态和清理逻辑。
- 修改 `test/skin.test.js`：覆盖请求取消、提交时序、历史索引回滚、双轴滚动恢复、帖子默认开启/用户关闭、无效响应以及卸载清理。
- 修改 `test/skin-canvas.test.js`：断言顶部进度线、正文进入状态、过渡胶囊不遮正文和减少动效规则。
- 修改 `scripts/ios27-canvas-smoke.mjs`：验证浏览器中旧正文与氢壳稳定、加载线不拦正文、动态原生 UI 隐藏、提交动画收尾和滚动恢复。
- 只有若现有构建/测试暴露无法验证同源响应的必要元数据时，才扩展网络响应元数据；默认不改 `src/net.js`。
- 只读参考脚本 `LINUX SB 逛吧「新大陆」-2.0.0.txt` 保持不变。

## 验收标准

1. 导航等待期间同一颗氢壳和旧正文保持连接；原生 UI 即使动态重挂也不可见；顶部进度线不覆盖或拦截正文。
2. 有效响应提交一次，更新地址、正文和页面元信息，并运行新正文进入动效；缓存命中不闪加载线。
3. 新导航立即中止旧请求；旧请求、旧定时器和旧回调不能改写新事务任何状态。
4. 后退/前进恢复对应 `scrollX`/`scrollY`；未保存编辑取消后退时恢复原历史项；回复楼层或 hash 定位优先。
5. 帖子页软跳默认开启，升级时一次性迁移既有配置；之后用户可关闭；淘帖详情与写操作仍走原生生命周期。
6. 请求失败、重定向、无效帖子响应、皮肤停用和页面缓存恢复均清理事务状态并按情形回退，不留下加载线、忙碌标记或原生 UI 隐藏状态。
7. `prefers-reduced-motion` 下无位移动画；主题标题播报和焦点变化可通过自动化测试验证。
8. 聚焦单元测试、Chromium 多视口冒烟、release/dev 构建与产物校验、全量测试通过。

## 全局约束

- 保留单一氢壳和当前插件/基座集成接口。
- 只对本站同源、明确允许的只读路由执行软跳。
- 不改变帖子写操作、淘帖详情和事务页面的整页生命周期。
- 不修改参考脚本，不清理或覆盖无关未提交改动，不提交。
