# skin 资料卡与站点卡片拆分

第七阶段提取双界面的个人资料卡，以及单画布站点卡片的节点所有权。旧三段式右栏的缓存、在线状态与页签编排仍留在模板；配置适配与 SPA 请求事务属于后续阶段。

## 模块边界

- `profile-controller.js`：实时读取页面、登录身份、原生侧栏、自身资料区宿主和视口；管理真实资料节点、原始位置、临时属性、展开事件、用户页资料槽和列表标记。提供 `adoptUserCard(host)`、`restoreUserCard()`、`isSelfUserCard(card)`、`mount(outlet)`、`restore()`、`updateScroll()`。
- `site-cards-controller.js`：管理单画布普通站点卡片原位与持久广告/每日热帖节点，提供 `sync(host, { persistentOnly })`、`restore({ releasePersistent, restorePersistent })`、`stageOrigins(remoteOutlet)`、`rebindOrigins(routeOutlet)`。不负责站点信息浮层可见性、宽度选择、网络、缓存或历史提交。
- 模板负责选择当前宿主、更新浮层状态和调用控制器；生成器增加两个显式注入点。

## 行为约束

1. 移动实际节点，保留输入值、表单、通知和广告事件；重复挂载、跨宿主移动和停用必须幂等。恢复只操作控制器持有的节点，不通过全局同名 class 猜测所有权。
2. 自己与被访问者按同源用户路径精确匹配，用户 12 不能匹配用户 123；未知登录身份保留原有降级。
3. 个人卡临时 ID、通知属性和事件在归还时撤销；他方在接管后更新的属性不被覆盖。恢复后旧展开按钮不能影响新资料区。
4. 连续普通卡片按原顺序归还；原宿主消失不能复活过期页面。广告/每日热帖保留原节点及已初始化状态，通过现有响应占位和重绑定流程跨软跳保存。
5. 不增加依赖，不改请求或写入权限，保持正式 21 / 开发 26 模块。skin 升至 2.0.42，Oxygen/LTS 升至 2.0.47，Hydrogen 保持 2.4.2。
6. 所有源码 UTF-8 无 BOM、LF。独立插件/dev/release/LTS 使用同一模块源，校验模式只读。沿用离线 Chromium 冒烟边界。

## 验收

先在旧独立插件复现错误资料节点归还、属性残留和身份前缀误判，再验证独立控制器的节点/事件/跨宿主和持久卡片行为。生成器测试验证新增源码实际进入产物、漂移与坏输入拒绝。最后执行完整构建、Node 回归与浏览器冒烟，并相对本轮工作区快照独立审查。
