# M17：iOS 27 单一阅读画布设计

日期：2026-10-03  
范围：`plugins/skin.user.js`、必要的 `src/shell-boot.js` 首屏背景预置、相关测试与套件产物同步。  
状态：设计已确认，等待实施计划审阅。

## 目标

氢壳彻底退出左栏 / 主栏 / 右栏三段式。首页、版块列表、帖子详情、个人页和设置页都使用一个连续的主滚动面；导航、站点信息、AI、外观设置和引用材料只在需要时从底部胶囊或内容上下文召回。

视觉基线向 iOS 27 靠拢：内容优先、玻璃表面、圆角卡片、低干扰状态条、底部 Sheet 和按需浮动卡片。透明度、模糊、背景视频、字体、字号、颜色和动效都可以在统一外观 Sheet 中修改。

M17 不重做站点内容或基座安全链。原生 DOM 仍是链接、编辑器、分页、引用和站内写操作的事实来源；氢壳只负责布局适配、表面层和交互编排。

## 非目标与约束

- 不改 linux.sb 服务端，不复制一套新的帖子、编辑器或写操作渲染器。
- 不把原生左栏、主栏和右栏作为三个固定窗口继续展示。
- 不恢复 `@当前页面`、`/提问类` 等模式选项卡；AI 由自然语言意图判断。
- 不绕过基座网络层、确认弹窗、CSRF、写操作结果检查或 M12/M14 的安全约束。
- 不把本地视频、字体或其他 Blob 写进配置 JSON、`localStorage` 或迁移 JSON。
- 不增加新的后台轮询或站内请求；Surface 只读取当前页面和已有模块数据。

## 架构

采用“单一画布适配层”，而不是新渲染层或纯 CSS 收拢。

### PageAdapter

PageAdapter 根据 `api.page.type` 和当前路由识别首页、版块列表、帖子、个人页和设置页。它只给现有主内容添加单画布类、阅读宽度和间距，不重建内容节点。

路由或 SPA 变化时，PageAdapter 更新页面标题、站点名、材料数量、当前阅读锚点和可用动作。原生内容、表单、分页、编辑器和链接节点保持原位置，避免事件、焦点和写操作分叉。

原生顶栏和 `aside.sidebar` 可以通过现有 `lsb-native-*` 状态隐藏，但节点不被移动到 `#lsb-shell`。移动端菜单抽屉仍由站点自己的节点负责；氢壳不把原生左侧板块栏复制进表面层。

### CanvasSurfaceHost

在 `body` 下建立单独的 surface 宿主，和站点正文同级。宿主只承载氢壳表面，不包裹、不替换正文。

表面类型：

- `top-status`：顶部可收窄玻璃状态条，显示返回、当前站点、材料数量和更多动作。
- `tool-capsule`：底部固定胶囊，提供阅读状态、导航、AI 和更多入口。
- `tool-sheet`：统一工具面板，显示导航、站点信息、AI 助理和外观四个快捷动作，以及统一自然语言输入。
- `ai-card`：悬浮 AI 卡片，显示当前材料、有限历史和生成状态，可展开为更大对话区域。
- `site-card`：底部站点摘要卡，显示站点身份、统计和进入站点设置的动作。
- `navigation-sheet`：底部导航 Sheet，显示当前站点、站点板块、最近访问、收藏和搜索。
- `appearance-sheet`：统一外观 Sheet，显示三种预设和全部自定义控件。
- `context-pill`：选中文本或当前帖子附近的回复、引用、收藏、复制和更多操作。
- `evidence-card`：引用材料卡，显示楼层、版本、复核状态和差异。

### SurfaceManager

SurfaceManager 统一处理表面的打开、关闭、焦点、拖动、缩放、层级和宽度降级。

- 同时只允许一个主 Sheet 打开；AI 卡、站点卡和引用卡是当前 surface 的浮动子层。
- 打开新主 Sheet 时关闭前一个主 Sheet，保留正文滚动位置。
- 桌面浮动卡通过 pointer capture、`requestAnimationFrame` 和 `translate3d` 更新，拖动中不做网格吸附，松开时再持久化。
- 卡片的关闭按钮、提交按钮和拖动区域互不重叠；键盘可以移动、缩放、提升/降低层级并关闭卡片。
- `wide (≥1100px)` 显示浮动卡；`mid (700–1099px)` 将浮动卡吸附为底部 Sheet；`narrow (<700px)` 使用单一可滚动全屏 Sheet。
- `prefers-reduced-motion` 时关闭位移动画；`prefers-reduced-transparency` 时使用实底；不支持 `backdrop-filter` 时使用同色实底。

### ContextController

ContextController 生成只读上下文快照，内容包括：

- 当前 route、站点 origin、帖子/楼层标识和阅读位置；
- 用户选中的文本和触发动作；
- 当前页面材料、材料取消状态和引用快照；
- 当前会话 id、M12 有限只读历史和生成控制状态；
- 当前 surface、焦点来源和可用的站内动作。

快照只供 AI、引用复核和显示层读取。它不能直接执行站内写操作，写操作必须回到现有确认、提交和结果检查链。

## 关键交互

### 阅读状态与工具入口

顶部状态条在向下滚动时收窄为低干扰玻璃条，向上滚动恢复完整信息。它不承载固定导航栏，不覆盖正文首行。

底部胶囊始终提供低干扰的召回入口。点击后打开统一工具 Sheet；Sheet 中的快捷动作是普通按钮而不是模式选项卡。自然语言输入由意图判断决定走导航、站点、AI 或其他已有能力。

### AI 对话

点击 AI 助理后出现悬浮 AI 卡片，卡片显示当前材料条、有限只读历史、回答和底部输入框。卡片可展开，但正文上下文、当前会话 id 和材料取消状态不变。

- 材料条的 `×` 只取消本次请求的当前页面材料；下一次请求重新按当前设置生成材料。
- 新会话生成新的会话 id；历史不会跨会话串联。
- M12 的有限历史、缓存指纹、停止、迟到响应丢弃、流式/整段端点和网络中断处理全部复用。
- 历史中的写操作要求只作为文本上下文，不触发执行；站内写操作仍由用户主动点击并经过现有安全链。
- 失败时保留用户问题供手动重试；重试不得重复已确认的不可重试写操作。

### 站点信息与导航

站点信息从统一工具 Sheet 打开底部站点卡片，默认显示站点身份、主题/成员等摘要和“打开站点设置”动作。详细设置只有用户主动点击后才进入站点原生页面。

导航从统一工具 Sheet 打开底部导航 Sheet，包含当前站点、站点板块、最近访问、收藏和搜索。选择条目后回到原阅读位置。原生左栏仍保留在原 DOM 并隐藏，不会被克隆进氢壳。

### 正文操作与引用

点击帖子或选中文本后，在当前内容附近显示上下文胶囊。回复、引用、收藏、复制和更多动作调用既有站内动作；不会增加固定操作栏的列宽。

引用编号以正文内联徽标显示。点击徽标打开 evidence-card，按 M14 惰性重读回答引用涉及的楼层，比较材料快照后显示：

- `fresh`：材料与回答引用一致；
- `changed`：材料已变化，展示可展开差异；
- `unavailable`：无法重读，显示原因并保留原引用。

引用验证仍由本地材料完成，不能用模型文本自证引用。

### 外观设置

appearance-sheet 顶部显示三个预设：

- A 平衡玻璃：视频/静态背景、中等透明度和模糊，优先保证长文对比度；默认值。
- B 沉浸视频：更透明、更明显的视频背景；动效关闭或视频失败时自动回退。
- C 静态可读：关闭视频并提高内容表面不透明度，适合减少动效和长时间阅读。

预设下方提供背景来源、玻璃透明度、模糊半径、字体来源、字体大小、文字/强调色、圆角、动效和恢复默认按钮。所有控件在同一个可滚动 Sheet 中实时预览，不使用多余选项卡。

视频：仅接受 HTTPS URL 或本地文件，默认静音循环；加载失败、超限或 IndexedDB 不可用时回退静态背景。字体：支持系统字体、本地文件和 HTTPS URL；加载失败回退站点默认字体。

## 存储模型

新增版本化画布记录。实施时将以下逻辑结构映射到现有存储 API，保持字段语义和合并规则不变：

```text
canvasState = {
  version: 2,
  global: {
    preset: 'balanced-glass',
    appearance: { ... },
    surfaceDefaults: { ... }
  },
  sites: {
    '<origin>': {
      appearance: { ...overrides },
      layout: {
        wide: { ...surface positions },
        mid: { ...surface positions },
        narrow: { ...surface positions }
      }
    }
  },
  legacyLayoutSnapshot: { ... }
}
```

实现必须遵守以下规则：

- `siteKey` 使用 origin，避免不同站点共享覆盖；字段未覆盖时合并 global。
- 布局位置使用相对视口值和锚点保存，读取时夹紧到当前视口；Sheet 不保存绝对位置。
- `z` 只控制浮动卡层级，焦点顺序仍遵循 DOM 和键盘顺序。
- 视频/字体 Blob 保存在独立 IndexedDB store，配置只保存 media id、MIME 和 HTTPS URL。
- 50 MB 视频和 10 MB 字体上限在选择文件、写库和读取时都校验。
- 迁移导出携带版本、URL、media id 和布局元数据，不携带 Blob；缺少本地文件时显示可恢复提示。
- 保存采用防抖写入，写失败恢复上一次有效快照并提示用户。

## 迁移与生命周期

首次启用新画布时：

1. 读取当前 `skin` 配置和已有外观媒体引用。
2. 生成一次 `legacyLayoutSnapshot`，包含旧壳开关、左栏/主栏/右栏相关配置、时间轴状态和可识别的媒体设置。
3. 以 A 预设生成新 global；把现有墙纸 URL、本地媒体引用、透明度和模糊等可识别值迁入 global。
4. 旧三栏不转换成固定 surface；新布局按当前宽度桶使用默认位置，用户之后可自由拖动和缩放卡片。
5. 保留显式 `shell:false` 的用户选择；显式开启或缺省旧配置的用户进入新单一画布。

停用插件、关闭画布或 SPA 页面卸载时：

- 恢复被隐藏的原生顶栏、侧栏和移动菜单状态；
- 移除 html/body 状态类、注入样式、surface 宿主和所有 object URL；
- 取消拖动、媒体加载、滚动和路由监听；
- 恢复焦点和正文滚动行为，不修改站点节点内容。

## 错误、兼容性与安全

- 所有站内请求继续走基座网络层；外部模型请求遵守现有 external/timeout/取消规则。
- 站内非幂等请求不自动重试；AI 失败重试只重试模型请求，不重放已确认的站内写操作。
- 找不到页面节点时跳过对应 surface，不抛出并保留正文可用。
- CSP、浏览器不支持 backdrop-filter、媒体加载失败、字体解码失败和 IndexedDB 不可用均有实底/站点字体/静态背景降级。
- 低宽度下所有 Sheet 可滚动，关闭、提交、停止和重试控件必须保持可见或可通过键盘到达。
- 用户减少动效/透明度时不播放视频、不做拖动位移动画、不使用无限动画。

## 测试与验收

### 纯函数与状态

- origin siteKey、宽度桶和布局边界夹紧；
- global 与 site override 合并及恢复默认；
- A/B/C 预设生成和细项覆盖；
- 旧配置迁移、版本补全和 legacy snapshot；
- HTTPS、本地文件大小、媒体 MIME 和字体回退校验；
- SurfaceManager 状态转移、主 Sheet 互斥、层级和焦点回退。

### DOM 与交互

- 五类页面均只有一个主滚动面；无固定左栏/主栏/右栏；原生左栏不进入氢壳；
- 顶部状态条收窄/恢复、底部胶囊和统一工具 Sheet；
- AI 卡、站点卡、导航 Sheet、外观 Sheet 和引用材料卡的打开/关闭/焦点；
- 桌面指针拖动、缩放、层级、键盘等价操作和坐标持久化；
- 中屏吸附、窄屏全屏 Sheet、减少动效/透明度和无 blur 降级；
- 停用、路由切换、异常销毁后节点、监听、object URL、滚动和焦点收摊。

### AI、引用与安全链

- 新会话与站点隔离；有限只读历史不会执行写操作；
- 材料 `×` 只影响当前请求；停止后输入可立即继续；迟到响应被丢弃；
- 流式/整段回答、网络中断、手动重试和写操作结果检查；
- 引用按楼层惰性复核，fresh/changed/unavailable 三态和差异渲染；
- 回复、引用、收藏等站内动作仍确认、提交、检查结果，不重复提交。

### 交付验证

每次交付运行完整 `npm test`、`npm run build`、产物同步校验和 `git diff --check`，然后在真实浏览器覆盖首页、版块列表、帖子详情、个人页和设置页的 wide/mid/narrow 路径。验证视频/字体来源、外观预设、旧布局迁移、恢复默认、键盘操作和减少动效/透明度设置。

## 交付拆分

- **M17.1 画布与 surface 宿主**：PageAdapter、单一主滚动面、顶部状态、底部胶囊、统一工具 Sheet、原生侧栏隐藏/恢复、宽度降级。
- **M17.2 外观与布局持久化**：A/B/C 预设、统一外观 Sheet、视频/字体 IndexedDB、全局/站点覆盖、拖动/缩放、旧三栏迁移和恢复默认。
- **M17.3 内容上下文与回归**：AI 悬浮卡、站点卡、导航 Sheet、上下文胶囊、M12/M14 接口接入、引用复核、完整测试和真实浏览器验收。

M17.1 完成后先做单画布结构回归；M17.2 完成后做迁移与媒体验收；M17.3 完成后才能宣称本轮架构重构完成。
