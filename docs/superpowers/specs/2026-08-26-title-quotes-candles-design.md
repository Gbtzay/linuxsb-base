# 称号行情：挂单合成 K

日期：2026-08-26  
范围：`plugins/title-quotes.user.js` 各称号展开图改为挂单合成蜡烛；配套测试与氧补丁号。  
非目标：成交 K、量柱、总览四锚点改 K、改采集/存储/`MERGE_MS`、购买接口、氢、新 `ORDER` 模块、新配置项。

修订 [`2026-08-26-title-quotes-design.md`](2026-08-26-title-quotes-design.md) 的「各称号图」：不再画最低/最高双折线。顶部四锚点折线、巡检、快照格式不变。

## 问题

`/gacha_market` 没有成交明细，做不成真 K。本地已有每个称号的 `lo` / `hi` / `mid` 时间序列，可以把一段时间的挂单收成一根蜡烛，方便看盘口怎么走。必须标明这不是成交。

## 方法

纯函数 `foldCandles(series, key, { rangeDays, now })` 把快照收成 `{ t, o, h, l, c }[]`。`t` 是桶起点。渲染共用 640×248 的时间轴图框（网格、价格刻度、起止时间）；所选范围内若数据更短，轴贴齐实际有点的区间，避免半幅空白。氧面板与交易页同一套 `render`。

## 一根蜡烛

对某个称号、某个时间桶：

| 字段 | 值 |
|---|---|
| 开 `o` | 上一根的收；第一根用桶内第一笔 `mid` |
| 收 `c` | 桶内最后一笔 `mid` |
| 高 `h` | `o` 与同批 `mid` 的最大 |
| 低 `l` | `o` 与同批 `mid` 的最小 |

挂单最低 / 最高仍写在行标题，不进影线。巡检往往十几小时一笔，一桶里只有一个 `mid`：若开也用这一笔，几乎全是平线。开接上一根收，才能把相邻快照的涨跌收成实体。空档仍不补柱。`h`/`l` 一定包住 `o`/`c`。没有成交量，不画量柱。

周期跟天数按钮：7 天 → 4 小时；30 天 → 1 天；90 天 → 3 天。映射：

```
rangeDays <= 7  → 4 * 3600e3
rangeDays <= 30 → 864e5
否则            → 3 * 864e5
```

## 空档与下架

快照仍是稀疏点。只在该桶里真有挂单快照时才出柱，空档留白，不再用假平线把图填满。某次全场快照没有这个称号：该桶及之后无柱。周期：7 天 4 小时、30 天 1 天、90 天 3 天。时间轴按所选窗口对齐，不是按柱数均分。

时间轴按桶对齐（从范围内第一笔所在桶到 `now` 所在桶），不是按稀疏下标均分。一根也画。从未出现过的称号不产出蜡烛。

## 外形

各称号 `<details>` 展开后：蜡烛图 + 一句 `挂单合成 · 非成交`（`.lsb-row-desc`）。涨（`c > o`）`#d94c4c`，跌 `#2a9a7c`，平盘灰。影线在下、实体在上；开收几乎重合画横刻，不画 1px 胖柱。空桶留白。总览四折线用同一套图框；锚点卡片带与折线同色的圆点。

零快照、仅一笔全场快照时总览文案不变（一笔仍提示再等一轮才出折线）。各称号在已有至少一笔含该称号的快照时就可以出 K。

## API 与存储

不改 `series` 形状。`title-quotes:debug` 增加 `foldCandles`、`periodMs`。类名只用 `lsb-title-quotes*`（蜡烛根节点 `lsb-title-quotes-k`）。

## 错误

采集失败路径不改。没有蜡烛时该行不放空 SVG，不另 toast。

## 测试

`test/title-quotes.test.js`：

- 同一小时三笔 → 一根：`o` 第一 `mid`，`h`/`l` 含开收与同批 `mid`，`c` 最后 `mid`。
- 相邻两桶 `mid` 从 10 到 20：第二根 `o` 为上一根收 10，`c` 为 20。
- `c >= o` 为涨。
- 两笔相隔 3 小时、中间无快照、仍在售 → 空档不补柱。
- 后一笔全场快照没有该称号 → 该桶及之后无 K。
- `periodMs(7/30/90)` 分别为 4h / 1d / 3d。
- 面板：总览仍是 `polyline`；点开某行有网格与影线/实体、有「挂单合成 · 非成交」；不请求 `/gacha_market_buy`。
- 原有用例保持绿（「两次出线」指总览折线；一笔全场快照时总览仍无 `.lsb-svg`，各称号行可以有 K）。
