# 统一阅读中心（首版）

目标：用户从一个入口找回最近读过或准备稍后阅读的帖子，按保存的页码和楼层继续阅读。

- 独立 `reading-center` 模块进入开发和正式 Oxygen；LTS 继续冻结新模块。
- 两个页签：最近阅读、稍后阅读；支持本地标题/主题 ID 搜索。
- 最近阅读的唯一来源为 `resume-reading:positions`，直接兼容旧格式 `{ f, p, title, ts }`，不复制历史、不抓取帖子。
- `resume-reading:list` / `resume-reading:get` 提供正式只读 RPC，返回 `{ topicId, title, floor, page, updatedAt, source, href }`。数据按时间倒序、应用原有容量和保留天数，过滤无效记录，返回独立值。
- 断点追踪随帖子路由启停；保存时捕获主题 ID、页码和标题，旧页面的延迟回调不能写入新帖子。原有 NEW 与续读提示保留。
- 稍后阅读使用阅读中心自己的 `later` 单键，按主题 ID 去重，保存标题和加入时间，最多 500 帖，无自动过期。满额明确提示，不能静默删除用户保存项。
- 在帖子列表、帖子正文标题旁提供「稍后阅读」开关；中心可以从历史添加或移除。继续阅读优先使用最新断点，缺少断点则打开主楼。稍后阅读不是站点收藏，也不表示已读完。
- 入口复用基座面板：两种 skin 的插件功能入口均可打开；未安装 skin 及窄屏 legacy 可从基座面板打开。
- 来源停用时展示说明，稍后阅读仍可使用；阅读中心停用后移除按钮、入口、RPC 和订阅，已保存数据保留。
- 打开、切换、搜索、添加、移除均不发送站内请求。显示标题必须转义；链接只根据已校验的主题 ID、页码、楼层生成。
- 面板打开、窗口恢复焦点及本地事件时重读存储；不承诺多标签同时写入的事务合并。

验收：旧记录首页可见；精确页码/楼层续读；队列持久化/去重/移除/满额提示；双界面与触屏无横向溢出；停用降级和软导航不串帖；无额外抓取；完整构建和回归通过。
