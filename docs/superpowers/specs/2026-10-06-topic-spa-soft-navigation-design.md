# 帖子 SPA 无感软跳设计

## 目标

把同源 `/topic/<id>` 纳入现有氢壳单画布的 SPA（单页应用）软跳事务。首页或其他已支持软跳页面点击帖子时，保留当前氢壳、顶部状态栏、底部工具胶囊和旧正文，等待远端帖子 HTML 完成后只原子替换正文出口；整个过程中原站顶栏、侧栏和旧三栏 UI 不得闪回。

## 范围

本次只扩展现有 `plugins/skin.user.js` 的软跳事务，不重写帖子模板，也不复制站点脚本。支持：

- `/topic/<id>` 以及帖子分页 `?p=<n>`；
- 带 `replyid`、`floor` 的帖子定位查询参数；
- 首页、版块、用户页、精华页等已支持壳内页面到帖子的软跳；
- 帖子页分页在帖子路由之间的软跳；
- 浏览器后退/前进、同一颗氢壳和原生帖子交互的连续性。

淘帖详情、发帖、称号交易、认证中心等仍按现有整页路由策略处理。列表页分页仍交给现有无限滚动或整页导航，不因帖子分页支持而改变。

## 现状根因

现有 `isSpaUrl()` 主动排除 `/topic/<id>`，`onSpaClick()` 因此不会拦截首页帖子链接；浏览器开始整页导航，document-start 占位层随后覆盖原站首屏，皮肤重新挂载后才显示氢壳。视觉上表现为原站 UI 短暂闪回或内容突然消失。

现有软跳事务已经具备保留氢壳的能力：请求期间保留正文 outlet，使用内容范围的 `#lsb-shell-route-transition`，提交前隐藏原生 chrome，提交后通过 `commitRoute()` 替换 outlet，并使用 `spaSerial` 防止过期请求回写。帖子路由应复用这条链路，而不是创建第二套导航系统。

## 设计

### 1. 路由白名单和点击策略

`isSpaUrl()` 接受严格的同源 `/topic/<正整数>` 路径，可带合法查询参数；仍拒绝外链、下载、新窗口、站点动作标记和淘帖详情。`onSpaClick()` 只对帖子分页放开例外：当前路由或目标路由为 `topic` 时允许帖子分页进入 `navigateSpa()`，首页/版块等列表分页继续保持原有排除逻辑。

帖子链接点击后立即 `preventDefault()` 并启动事务。document-start 的导航保护仍可短暂加上 leaving 标记，但在同一 click 事件被 SPA 取消后立即撤销；当前文档不会离开，因此不会创建新的首屏占位层。

### 2. 事务和原子提交

事务阶段保持 `preparing → fetching → committing → settling → settled`，每个异步阶段都同时校验 `serial === spaSerial`、过渡节点身份和目标 URL。请求期间：

1. 设置当前 outlet 的 `aria-busy="true"`；
2. 创建或复用内容范围过渡层；
3. 保留当前 outlet 及其中的旧帖子；
4. 隐藏原生顶栏、侧栏和左侧固定栏；
5. 不重建 `#lsb-shell`、顶部状态栏、站点信息栏或底部工具胶囊。

远端文档解析后只取 route outlet 的子节点，剥离 `script`，在连接到当前文档前给远端侧栏加隐藏类。提交时一次性更新 outlet 属性和子节点，刷新 `document.title`，然后更新浏览器历史。提交失败时恢复 `aria-busy`，过渡节点只由当前事务清理；未提交的请求失败按原有策略回退整页导航。

### 3. 帖子路由同步和插件交互

提交新帖子正文后触发一次受控路由通知，使基座重新解析 `site.snapshot()`，更新 `api.page`、CSRF 和帖子快照，并按页面类型启停帖子专属插件。氢壳自身继续使用同一壳节点，`fillShell()` 只重新同步页面类、用户卡、站点卡、标题、背景和滚动绑定。

站点主脚本已有 document 级表单/点击委托，回复、收藏、投币等新 DOM 不通过重新执行远端脚本来激活。软跳层补充以下适配：

- 帖子分页链接进入同一事务；
- `replyid` 或 `floor` 在提交和浏览器后退恢复后定位对应楼层；
- 新帖子 DOM 通过现有 `topic:posts-added`/DOM 观察链路交给阅读标记、AI 采集、楼层统计等插件；
- 不对远端脚本执行 `eval`，不复制或重建氢壳节点；
- 当前打开的氢浮层在路由切换时按现有互斥规则关闭或保持，不让旧页面节点引用新页面。

### 4. 错误、取消和历史

快速连续点击时递增 `spaSerial`，旧请求只允许返回结果，不允许改变 DOM、URL、滚动、过渡层或通知。浏览器后退/前进使用 `historyMode: 'none'`，缓存页面与网络页面共用同一事务。非 SPA 地址（发帖、交易、帖子收藏等整页端点）被后退命中时沿用现有整页重开判断。

目标楼层不存在时不报错，不改变内容，只保持页面顶部；无效或跨源 `replyid`/`floor` 不参与 DOM 查询。

## 测试和验收

- 单元/DOM：从首页点击帖子时，请求未完成前旧 outlet、顶部状态栏、底部胶囊和壳节点身份不变；不存在整屏 route shield；阶段为 `fetching`。
- 单元/DOM：帖子请求完成后地址为 `/topic/<id>`，正文替换为帖子内容，远端脚本未执行，帖子页类和 `api.page.type` 为 `topic`。
- 单元/DOM：帖子分页进入软跳，`replyid`/`floor` 定位安全；列表页分页仍不被拦截。
- 单元/DOM：快速连续帖子导航只允许最后一个事务提交。
- 浏览器冒烟：延迟首页到帖子响应，确认原生顶栏/侧栏计算样式为 `display:none`，氢壳和顶部状态节点保持同一 DOM 节点，并截图记录过渡期间。
- 浏览器冒烟：帖子页分页后仍能找到回复表单、收藏按钮和投币/反应区域，后退可回到首页而不重建氢壳。
- 全量测试、产物校验和现有 iOS 27 画布冒烟必须通过。
