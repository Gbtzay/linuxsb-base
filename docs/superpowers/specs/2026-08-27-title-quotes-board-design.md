# 称号行情：分析大盘

日期：2026-08-27  
范围：`plugins/title-quotes.user.js` 增加「大盘」视图（指数 K、稀有度档、均线/布林、冷热榜）；插件 `1.0.9` → `1.0.10`；氧 `SUITE_VERSION` / `suite-center` `1.0.83` → `1.0.84`。氢、皮肤、`ORDER` 不动。  
非目标：成交量 / 真成交 K、`/gacha_market_buy`、新插件、氧侧栏新入口、新网址、持久化指数序列、记住停在大盘、均线开关、按挂单条数 `n` 加权、改四锚点折线、改各称号图、改采集 / `MERGE_MS` / 快照格式。

## 问题

行情页已有全场四锚点折线和各称号挂单 K。用户要单独一页看「大盘」：按稀有度分层的指数、全场总指数、均线与布林、短线/区间冷热榜。数据仍只有挂单高低和中位数，没有成交。

## 方法

同一插件、同一份 `series`、同一套 `render`。交易页嵌入和氧面板 Tab「称号行情」都出现「行情 | 大盘」。大盘上的指数、均线、榜都从快照**当场重算**，不另存。纯读。

## 出现位置

折叠标题仍为「称号行情」。工具条左侧两个视图按钮：`行情` | `大盘`。默认 `行情`。内存变量，不写 `api.store`。刷新、重新进页、重新挂载插件后回到行情。

时间窗 `本日` / `7天` / `30天` / `90天` 两页共用同一个 `rangeDays`。`K线` / `折线` 只在行情页显示；大盘固定为指数 K + 叠加。

**行情页**：四锚点卡、全场锚点折线、各称号列表，与现在一致，只多视图切换。

**大盘页**：不渲染四锚点和各称号列表。自上而下：稀有度档 → 指数图（含均线/布林）→ 冷热榜。空数据沿用现有文案（还没采到 / 再等一轮 / 本轮失败），不画假轴。

## 指数

对每一份快照的 `titles`：

- 只计入当时有记录的称号，价格用 `mid`。
- 按 `rarity` 原文分组（空字符串单独一档，芯片文案为「未知」）。
- **档指数** = 该档各 `mid` 的算术平均。该档 0 个称号：该时点无点，不拿旧价填。
- **总指数** = 按该档称号个数加权，等于全场 `mid` 的等权平均。挂单条数 `n` 不参与。

不把指数写入 `series`。

合成 K：把所选序列收成 `{ t, mid }` 点列，再用与 `foldCandles` 相同的桶规则（`periodMs`、`rangeCutoff`、本日空窗不回退到全部历史、空桶跳过、下一根开 = 上一根收）。总指数缺测时点：该快照没有任何在售称号。某档缺测：该快照该档无称号。

默认画总指数。芯片列出当前时间窗内出现过的稀有度，按**最新快照**该档称号个数降序，个数相同则 `localeCompare('zh-CN')`。点芯片只换图上那条 K；总是可以点回「总指数」。

## 均线与布林

只叠在大盘当前这条指数 K 上。各称号图不加。

对 K 数组（按下标，不按日历补洞）：

| 线 | 规则 |
|---|---|
| SMA 5 | 最近 5 根收盘平均；不足 5 根不画该点 |
| SMA 20 | 最近 20 根收盘平均；不足 20 根不画 |
| 布林中轨 | SMA 20 |
| 布林上/下轨 | 中轨 ± 2 × 这 20 根收盘的总体标准差（除以 20，不是 19） |

三条均线/轨道默认全开，无开关。快照稀疏造成的 K 断档处，叠加线也断开（相邻有值的点不跨空洞连线）。

Y 轴计算纳入：可见 K 的开高低收，以及该根已算出的均 5 / 均 20 / 上下轨，避免布林被裁切。

悬停仍用现有 K 热区。提示在开高低收、涨跌后面追加该根已有的 `均5` / `均20` / `上轨` / `下轨`；没有的项不写。行情页各称号 K 的提示不变。

## 冷热榜

指数图正下方。`短线` | `区间`，默认短线。窄屏两表上下叠，宽屏并排。

比较对象：

- **短线**：最新快照 vs 其前一份全场快照（不受时间窗裁切）。只有一份快照：无涨跌；当前在售全部算新上；无下架。
- **区间**：最新快照 vs 当前时间窗内**最早**那份快照。本日窗内没有点：不回退历史，榜空。

涨跌幅 = `(现 mid − 基 mid) / 基 mid`。基为 0 或不存在：该称号不进涨跌榜。平盘（0%）两侧都不进。

**新上优先于涨跌**：现有、基快照没有 → 只进新上摘要，不进涨跌。**下架**：基快照有、现在没有 → 只进下架摘要。区间涨跌因此只比较「窗起点快照与现在都有」的称号，基 = 起点快照的 `mid`。

两表：**涨幅 Top 10**、**跌幅 Top 10**（不足则全列出）。排序用涨跌幅，并列按称号键 `localeCompare('zh-CN')`。列：称号、稀有度、当前中位、涨跌点数、涨跌幅。下架无「当前中位」，只出现在摘要。

摘要一行：`新上 N：…`、`下架 M：…`，名称可点。没有则不写那一侧。名称最多列出 20 个，超出写「等」。

点称号（榜或摘要）：切到行情视图，展开该 `data-key` 行（已下架行保持 `is-off`）。交易页嵌入若折叠着，一并展开折叠。

## 结构

纯函数与 `foldCandles` 同层，经 `title-quotes:debug` 导出供测试。建议切分：

- `mean(nums)` → 算术平均；空数组返回 `null`
- `snapshotIndex(titles)` → `{ overall, byRarity: { [rarity]: { mean, n } } }`
- `indexPoints(series, rarity)` → `{ t, mid }[]`；`rarity === null` 为总指数（不用空字符串，避免和稀有度原文 `''` 冲突）
- `foldIndexCandles(points, { rangeDays, now })` → 与称号 K 相同的 `{ t, o, h, l, c }[]`
- `sma(values, n)` / `stdevPop(values)` / `bollinger(closes, n=20, k=2)`
- `overlays(bars)` → 每根可选的 `{ sma5, sma20, bbUpper, bbMid, bbLower }`
- `movers(latest, base)` → `{ up, down, listed, delisted }`（先分类新上/下架，再对交集算涨跌，截断 Top 10）

`render` 用内存 `boardView`（`quotes` | `board`）和 `boardRarity`（`null` 表示总指数，否则稀有度原文，可为空字符串「未知」）。不改 `pushSnap`、采集、`snapSig`。

插件变大但逻辑仍在本文件；不拆新模块、不进氢。

## 错误

采集失败行为不变。大盘在无成功 `series` 时与行情同一套空状态。指数或榜在窗口内算不出柱/行时：图位空文案「这个时间窗还不够画指数」，榜位空文案「没有可比的涨跌」；新上/下架仍可单独出现。
