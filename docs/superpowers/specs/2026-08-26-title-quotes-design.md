# 称号行情设计

日期：2026-08-26  
范围：新插件 `plugins/title-quotes.user.js`（显示名「称号行情」）；皮肤左栏工具入口；套件 `ORDER` / README / `SUITE_VERSION`。  
非目标：K 线、成交记录、买入/挂单、桌面通知、自选关注、价格预警、改氢 / `site.js`。

## 问题

`/gacha_market` 只有在售挂单。成交记录仅交易双方可见，做不成 K 线。用户要看的是：全场谁最贵、谁最便宜、中位附近是谁，以及每个称号挂单高低价怎么走。

## 方法

氧模块 `title-quotes`。定时拉交易页挂单（按等级拆开，各拉一次低到高 / 高到低），按称号合并最低 / 最高 / 中位数，落本地时间序列。面板和交易页共用同一份快照画 SVG 折线。纯读，不提交 `/gacha_market_buy`。

氢不改。选择器只写在本插件顶部。站点改版只动这一处。

## 出现位置

不设 `pages`：巡检要在任意页跑。注入只认路径 `/gacha_market`。

- 氧面板 Tab「称号行情」（`order` 紧挨积分趋势）。
- 氢壳左栏「工具」：插件 `active` 时多按钮「称号行情」，`openPanel('title-quotes')`。插在「积分趋势」和「年度报告」之间。
- 交易页：在「在售交易」那节之前插入 `.lsb-title-quotes-embed`，内容和面板相同。SPA 再进该路径则重挂（已有节点则只刷新，不复制）。

## 总体图

顶部四块锚点，每块：称号名、稀有度、价格。

1. **最高**：当次全场挂单单价最高的那一条（价 = 该条单价）。
2. **中位偏上** / **中位偏下**：各称号先算自己的挂单中位数，按中位数升序；规则见下。价 = 该称号中位数。
3. **最低**：当次全场挂单单价最低的那一条（价 = 该条单价）。

同价并列只留解析到的第一条。在售称号不足 4 个时有几个示几个，不硬凑。同一称号可以同时是最高和最低（全场只有它，或最贵和最便宜都是它挂的）。中位块不再用已经占了最高或最低的称号。

中位两人算法（按中位数排序后的列表 `S`，长度 `n`，且已去掉占了最高/最低的称号）：

- `n === 0`：无中位块。
- `n === 1`：只出「中位偏下」。
- `n >= 2`：偏下 = `S[floor((n-1)/2)]`，偏上 = `S[ceil((n-1)/2)]`；若两者相同则偏上 = 下一个更贵的（没有则只出一块）。

下面 SVG 四折线（缺的锚点不画）：全场最高、中位偏上、中位偏下、全场最低。中间两条跟「当时占着中位的称号」的价格，不锁死名字。名字只写在四块上。

时间范围 7 / 30 / 90 天，默认 7，总体图与各称号图共用。零快照：空文案，不画轴。一次快照：四块现价可出，折线提示再等一轮。两次及以上出线。

## 各称号图

每个在快照里出现过的称号一行。标题：名、稀有度、当前最低 / 最高；不在当次在售则标「已下架」，旧线保留。默认折起，点开才展开双折线（该称号最低挂单、最高挂单）。排列：仍在售的按当前最低价升序，已下架放最后。新称号自动入列。

## 采集

`api.election` 选主。默认间隔 30 分钟（配置 `intervalMin`）。打开 `/gacha_market` 的标签立刻补采（`force`，follower 也采），5 秒防抖。失败不另开重试风暴，等下一轮。在途 Promise 复用，不丢弃并发调用。

每一轮 10 次 `api.net.doc`，顺序走基座限速队列：

`rarity ∈ {ur,ssr,sr,r,n}` × `sort ∈ {price_asc,price_desc}` → `/gacha_market?rarity=&sort=`。

卡片：`.gacha-market-card`；名 `.gacha-title-name`；稀有度 `.gacha-title-rarity`；单价 `form[data-gacha-market-price]`；去重键 `input[name=listing_id]`。两页重复 id 只计一次。

每个称号（键为 `名@稀有度`，避免重名）：`lo = min(单价)`，`hi = max(单价)`，`mid` = 单价数组排序后的中位数（奇数取正中；偶数取两中点算术平均后 `Math.round`）。

当次 0 张卡：视为空市，**不覆盖**上次成功快照，只记失败/空市时间。

## 存储

`api.store` 键 `series`，默认留 90 天（`keepDays`）。

一条快照：

```
{ t, anchors: [{ role, name, rarity, price }], titles: { "名@稀有度": { rarity, lo, hi, mid } } }
```

`role` 为 `hi | midHi | midLo | lo`。高低价、中位数、锚点称号与价格相对上一条都没变：12 小时内只把上一条 `t` 推到现在；满 12 小时再写一条（横盘也能出平线）。有变化则立刻 push。然后按 `keepDays` 修剪。

## 错误

拉页或解析失败：保留上次成功数据；区块标「上次采集 … · 本轮失败」。整轮最多一条 toast。不发桌面通知。

## 生命周期

`onDispose`：清定时器、摘交易页插入节、退选主。`route:changed` 与首次加载：若路径是交易页则挂节点并 `force` 采。`api.handle('title-quotes:debug')`：series、lastErr、lastAt、armed、snap、reset。类名只用 `lsb-title-quotes*`。

## 测试

`test/title-quotes.test.js` + 交易页卡片夹具（不必整页）：

- 同称号多单价 → lo / hi / mid。
- asc + desc 合并、listing_id 去重 → 高低不被单页 100 条截断。
- 中位数排序 → 四锚点符合规则；少于 4 个称号不硬凑、最高/最低与中位不重复占角。
- 12 小时内两次同价 → 只推进 `t`；隔 12 小时以上同价 → 新开一条。
- 零快照空状态；一次快照有锚点无折线；两次以上出线。
- 交易页夹具出现插入节；测试过程不出现对 `/gacha_market_buy` 的请求。

`test/skin.test.js` 左栏工具列表加上「称号行情」（需同时加载本插件）。`ORDER` 放在 `points-ledger` 之后。

不测：真站巡检、10 路实网、购买表单。
